# Data inventory and regeneration guide

The `data/` directory stores processed inputs and intermediate products used by the
subduction detection algorithms and figure scripts. Most source data are either
retrieved from the OneArgo toolbox, derived from manual event classifications, or
built from external carbon sequestration resources. The table below summarises how
each file is produced and the external assets you need to reproduce it.

| File | What it contains | How to obtain / regenerate |
| --- | --- | --- |
| `co2_sequestration_50years.csv` | 50-year sequestration fractions (`fseq`) interpolated onto the upper-ocean grid. | Run `OLD_script/06SiegelCorrection.ipynb` after downloading the OCIM-2 sequestration dataset (`fseq_OCIM2_48L.nc`) from BCO-DMO (dataset 869962 / https://doi.org/10.6075/J0Q81B3J). Update the notebook paths to point at the downloaded NetCDF, execute all cells, and export the CSV. |
| `dataframe_full_mld_and_n2.csv` | Profile-level feature set (MLD, N², anomaly flag) used for GAM fits. | Execute `OLD_script/04SpatialTemporalIntegrated.R` once the following inputs are present: (i) `df_argo_loc.csv`, (ii) `df_carbon_subduction_anom.csv`, (iii) `data/mld_results.csv`, and (iv) `data/N2_results.csv`. The last two come from the vertical stability pipeline (contact maintainers if you do not already have them). The script binds the anomaly catalogue to background profiles and writes the combined frame. |
| `detected_physical_subd_events.csv` | Physical subduction anomalies detected from Argo oxygen/salinity. | Run `scripts/detection_algorithm_physical_subduction.R` with a vector of WMO identifiers (see main README for details). The script writes the consolidated detection list here. |
| `df_argo_loc.csv` | Location and timestamp of all analysed Argo profiles. | Produced by `OLD_script/04ManualClassificationOfEvents.R` when you provide the full Argo profile extract (`data/argo_profiles_df.csv`) together with the manually reviewed detection catalogues (`detected_events_abs_sal_var_v5.csv`, `anom_in_spic_and_sal_cat1_and2.csv`, `classification_results_salinity_fig_not_in_spic.csv`, `deep_classification.csv`). |
| `df_carbon_subduction_anom.csv` | Manually verified carbon subduction events (WMO, cycle, metadata). | Also written by `OLD_script/04ManualClassificationOfEvents.R` after combining the manual classification spreadsheets `data/carbon_cat1_class.csv` and `data/carbon_cat2_class.csv` with the physical anomaly metadata. |
| `df_carbon_subduction_anom_with_poc_fromgali.csv` | Carbon anomaly catalogue with depth-resolved particulate organic carbon (POC) estimates. | Run `OLD_script/04CarbonQuantificationOnAllFloats_Gali2022.R`. The script uses `oneArgo::load_float_data()` to fetch the float profiles referenced in `df_carbon_subduction_anom.csv`, applies the depth-dependent Gali et al. (2022) conversion, and saves the enriched table here. |
| `df_carbon_with_POC.Rds` | Seasonal carbon export estimates under exponential decay scenarios. | Generated by `OLD_script/05EstimationofEddyPump.R` using the POC-enriched catalogue and the Siegel et al. sequestration grid (`co2_sequestration_50years.csv`). The script writes several RDS/CSV outputs in `data/`, including this file. |
| `df_meanseq.csv` | Depth-by-location average sequestration fraction. | Created in `OLD_script/06SiegelCorrection.ipynb` alongside `co2_sequestration_50years.csv` when the OCIM-2 dataset is processed. |
| `export_region.csv` | Regional carbon export summary across sensitivity experiments. | Saved by `OLD_script/05EstimationofEddyPump.R` (look for the `write_csv(export_region, ...)` call). |
| `histogram_data_full_for_python.csv` | Subduction timing histogram inputs for the ESP notebook. | Run `OLD_script/04HistogramOfSeasonalityOfCarbonSubdWithMLD.R` to merge Argo coverage with the anomaly catalogue and write the histogram-ready CSV. |
| `manually_verified_physical_subd_events.csv` | Curated list of the physical subduction events used in the manuscript figures. | Exported manually from the classification workflow described in `OLD_script/04ManualClassificationOfEvents.R`. If you need an updated copy, re-run that script with the latest manual review spreadsheets or request the curated export from the maintainers. |
| `pred_full_carb025.Rds` | 0.25° GAM predictions of carbon subduction occurrence. | Produced by running the seasonal GAM workflow in `OLD_script/04Tweaking_GAM_Interpolation.R` after `df_carbon_subduction_anom_with_poc_fromgali.csv` is available. |
| `pred_full_subd025.Rds` | 0.25° GAM predictions of physical subduction occurrence. | Same workflow as above (`OLD_script/04Tweaking_GAM_Interpolation.R`), using the physical anomaly catalogue. |
| `sensitivity_region.Rds` | Regional sensitivity envelopes for export calculations. | Output of `OLD_script/05EstimationofEddyPump.R`, which sweeps a range of remineralisation timescales (`w` parameter) and stores the per-region bounds. |
| `sensitivity_res.Rds` | Global sensitivity summary by remineralisation time. | Also saved by `OLD_script/05EstimationofEddyPump.R` (see the `sensitivity_results` list). |

> **Note:** Several source spreadsheets (`manual_classification.csv`, `carbon_cat*_class.csv`, `mld_results.csv`, `N2_results.csv`, etc.) are not versioned in this repository because they contain large or proprietary datasets. Coordinate with the manuscript authors to obtain the latest copies before attempting to regenerate the derived files.
